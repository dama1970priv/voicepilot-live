# VoicePilot – aktuelle Version

Sprachsteuerung für Claude Code unter Windows.
Ein Produkt von **omento webdesign** · erstellt von **Markus Schartner**

Dieses Projekt enthält immer nur die **neueste Version** von VoicePilot.
Die installierte App prüft hier beim Start und alle 4 Stunden, ob es ein Update gibt, und bietet es direkt an.

**Download:** unter [Releases](../../releases/latest) die Datei `VoicePilot-Setup-<version>.exe`.

`latest.yml` enthält die SHA-512-Prüfsumme des Installers. VoicePilot installiert ein Update nur, wenn die Prüfsumme stimmt.
